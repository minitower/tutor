# Модуль 2 — MCP: подключаем агента к внешним системам

## Цели обучения
- Понимать, какую проблему решает MCP, и подключать внешние системы к агенту безопасно

## Ключевые концепции
- Архитектура host / client / server, JSON-RPC, транспорты stdio и Streamable HTTP
- Примитивы: tools, resources, prompts; elicitation и расширения
- Практика: `claude mcp add`, `.mcp.json`, БД через MCP, открытые серверы, свой сервер на Python
- Выбор между MCP, CLI, Skill и hook
- Безопасность: injection через вывод инструментов, tool poisoning, supply chain, права; MCP в CI и мультиагентных системах

## Лабораторная работа
Подключите read-only БД через MCP, докажите, что запись заблокирована, напишите мини-сервер и проверьте его в Inspector.

## Результат
`.mcp.json` без секретов, трасса вызовов, код мини-сервера и заметка об угрозах с контрмерами.
