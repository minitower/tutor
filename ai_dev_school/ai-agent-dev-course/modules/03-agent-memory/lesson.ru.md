# Модуль 3 — Долгосрочная память агента

## Цели обучения
- Проектировать долгосрочную память агентной системы о пользователе и проекте — и проверять её тестами

## Ключевые концепции
- Контекст vs. память; рабочая, эпизодическая, семантическая, процедурная память
- Файловая память: `SOUL.md`, `USER.md`, `MEMORY.md`, дневные заметки; `SOUL.md` — соглашение, а не стандарт
- Многослойная память на примере TencentDB Agent Memory: слои L0–L3, Skill/Wiki/CodeGraph, MemoryProxy, ACL, поиск BM25 + вектор + RRF
- Своя память на SQLite FTS5; политика записи: что запоминать, а что нет
- Риски: memory poisoning, приватность, устаревание; тесты recall / изоляция / удаление

## Лабораторная работа
Соберите память ассистента (`SOUL.md`, `USER.md`, `MEMORY.md`), проведите три сессии, реализуйте SQLite-память и напишите тесты.

## Результат
Файлы памяти, лог сессий, код и тесты, заметка о политике памяти.
