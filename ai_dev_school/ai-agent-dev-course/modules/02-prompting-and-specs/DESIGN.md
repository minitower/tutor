# Bridino — руководство по дизайну и UI

Дизайн-система для свадебного казино Bridino. Документ описывает визуальный язык, токены и правила компонентов для гостевого и админского интерфейса.

---

## 1. Философия бренда

### Тон голоса (Tone of Voice)
- **Игривый, но понятный** — «сделай ставку», «твой выигрыш», без жаргона букмекеров
- **Праздничный** — это свадьба, не серьёзная биржа; допустимы лёгкие формулировки и эмодзи в заголовках (умеренно)
- **Прозрачный** — баланс, статус пополнения и коэффициенты всегда на виду, без скрытых условий

### Настроение
- **Казино-стол** — тёмно-зелёный фон, красные акценты, ощущение игрового зала
- **Свадебная элегантность** — золотые детали, аккуратная типографика, без кричащего неона
- **Mobile-first** — крупные зоны нажатия, читаемость при слабом свете банкетного зала

### Визуальная метафора
Зелёное сукно рулетки + красные фишки и акценты. Золото — для денег, баланса и «премиальных» элементов. Белый/кремовый текст — для контраста на тёмном фоне.

## 2. Цветовая палитра (токены)

Основные цвета бренда — **красный** и **зелёный**. Они используются последовательно: зелёный = фон и «спокойные» поверхности, красный = действия и акценты.

### Брендовые

| Токен | HEX | Назначение |
|-------|-----|------------|
| `felt-900` | `#0A1F17` | Основной фон приложения (глубокий зелёный) |
| `felt-800` | `#0F2D22` | Фон карточек, нижняя навигация |
| `felt-700` | `#1A3D2E` | Hover-состояния, вторичные поверхности |
| `felt-600` | `#2D6A4F` | Бордеры, разделители на зелёном |
| `casino-red-600` | `#C41E3A` | Primary: CTA, активные ставки, важные акценты |
| `casino-red-500` | `#E63950` | Hover primary |
| `casino-red-700` | `#9B1830` | Pressed / active primary |
| `casino-green-500` | `#40916C` | Secondary: подтверждения, выигрыш, «открыто» |
| `casino-green-400` | `#52B788` | Hover secondary |
| `gold-400` | `#D4AF37` | Баланс, фишки, коэффициенты, декоративные акценты |
| `gold-300` | `#E8C96A` | Подсветка сумм, иконки фишек |

### Нейтральные

| Токен | HEX | Назначение |
|-------|-----|------------|
| `cream-50` | `#FAF7F2` | Основной текст на тёмном фоне |
| `cream-200` | `#E8E0D4` | Вторичный текст, подписи |
| `cream-400` | `#A89F94` | Placeholder, disabled-текст |
| `ink-900` | `#1A1412` | Текст в светлой админ-панели |

### Семантические

| Токен | HEX | Использование |
|-------|-----|---------------|
| `success` | `#40916C` | Подтверждённое пополнение, выигрыш, статус `settled` |
| `warning` | `#D97706` | Ожидание (`pending`), скоро закроется |
| `error` | `#DC2626` | Ошибки, отклонённое пополнение, недостаточно средств |
| `info` | `#3B82F6` | Подсказки, информационные баннеры |

### Статусы событий

| Статус | Цвет | Пример бейджа |
|--------|------|---------------|
| `draft` | `cream-400` | «Черновик» |
| `open` | `casino-green-500` | «Принимаем ставки» |
| `closed` | `warning` | «Ставки закрыты» |
| `settled` | `gold-400` | «Рассчитано» |

### Tailwind-маппинг (рекомендуемый)

```js
// tailwind.config — расширение theme.colors
felt: {
  900: '#0A1F17',
  800: '#0F2D22',
  700: '#1A3D2E',
  600: '#2D6A4F',
},
casino: {
  red: { 500: '#E63950', 600: '#C41E3A', 700: '#9B1830' },
  green: { 400: '#52B788', 500: '#40916C' },
},
gold: { 300: '#E8C96A', 400: '#D4AF37' },
cream: { 50: '#FAF7F2', 200: '#E8E0D4', 400: '#A89F94' },
```

### Контраст и доступность
- Текст `cream-50` на `felt-900`: контраст ≥ 12:1
- Кнопки `casino-red-600` с белым текстом: ≥ 4.5:1
- Не полагаться только на цвет — дублировать статус текстом или иконкой

## 3. Типографика

### Требование: поддержка русского языка

Все шрифты **обязаны** иметь полноценную кириллицу (не только латиницу). Подключать через Google Fonts или self-hosted woff2.

| Роль | Шрифт | Обоснование |
|------|-------|-------------|
| **Заголовки (Display)** | [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) | Элегантность свадьбы, хорошая кириллица, контраст с UI-шрифтом |
| **Интерфейс (Body / UI)** | [Golos Text](https://fonts.google.com/specimen/Golos+Text) | Создан для русскоязычных интерфейсов, отличная читаемость на мобильных |
| **Числа и суммы (опционально)** | Golos Text `font-variant-numeric: tabular-nums` | Ровные колонки в таблицах и балансе |

**Запасной вариант UI-шрифта:** [Manrope](https://fonts.google.com/specimen/Manrope) — если Golos недоступен.

```css
/* Подключение */
@import url('https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600;700&family=Playfair+Display:wght@600;700&display=swap');

:root {
  --font-display: 'Playfair Display', 'Times New Roman', serif;
  --font-body: 'Golos Text', system-ui, sans-serif;
}
```

### Шкала размеров

| Стиль | Шрифт | Размер | Вес | Line-height | Применение |
|-------|-------|--------|-----|-------------|------------|
| `display-lg` | Playfair | 32px / 2rem | 700 | 1.2 | Заголовок экрана «Bridino» |
| `display-md` | Playfair | 24px / 1.5rem | 600 | 1.25 | Название события |
| `heading` | Golos | 20px / 1.25rem | 600 | 1.3 | Секции, карточки |
| `body` | Golos | 16px / 1rem | 400 | 1.5 | Основной текст |
| `body-sm` | Golos | 14px / 0.875rem | 400 | 1.45 | Подписи, мета |
| `label` | Golos | 12px / 0.75rem | 500 | 1.3 | Бейджи, метки статуса |
| `amount` | Golos | 28px / 1.75rem | 700 | 1.1 | Баланс, крупные суммы |
| `coefficient` | Golos | 18px / 1.125rem | 700 | 1.2 | Коэффициенты на кнопках исходов |

### Правила набора
- Суммы: `1 000 ₽` — пробел как разделитель тысяч, символ рубля
- Заголовки событий — sentence case: «Кто больше откусит икры»
- Не использовать ВСЕ ПРОПИСНЫЕ в UI (кроме логотипа BRIDINO)
- Минимальный размер интерактивного текста: **14px**

## 4. UI-компоненты и стили

### Скругления (Border Radius)

| Элемент | Значение | Tailwind |
|---------|----------|----------|
| Кнопки, инпуты | 8px | `rounded-lg` |
| Карточки событий | 12px | `rounded-xl` |
| Модальные окна | 16px | `rounded-2xl` |
| Бейджи статуса | 9999px | `rounded-full` |
| Фишка (декор баланса) | 50% | `rounded-full` |

### Тени

| Уровень | Tailwind | Применение |
|---------|----------|------------|
| Лёгкая | `shadow-sm` | Инпуты |
| Карточка | `shadow-md shadow-black/20` | Карточки на felt-фоне |
| Приподнятая | `shadow-lg shadow-casino-red-600/10` | CTA, выбранный исход |
| Свечение | `ring-2 ring-gold-400/50` | Активная ставка, фокус |

### Отступы (сетка 4px, базовый шаг 8px)

- Внутренние отступы экрана: `px-4` (16px)
- Между карточками: `gap-3` (12px) или `gap-4` (16px)
- Внутри карточки: `p-4`
- Минимальная высота кнопки: **48px** (touch target)
- Минимальная зона нажатия для исходов ставки: **56px** по высоте

### Кнопки

| Вариант | Фон | Текст | Когда |
|---------|-----|-------|-------|
| Primary | `casino-red-600` | `cream-50` | «Сделать ставку», «Пополнить» |
| Secondary | `felt-700` + border `felt-600` | `cream-50` | «Отмена», вторичные действия |
| Success | `casino-green-500` | `cream-50` | «Подтвердить» (админ) |
| Ghost | прозрачный | `cream-200` | Навигация, «Назад» |
| Disabled | `felt-700` | `cream-400` | Недоступное действие |

### Карточка события (Market Card)

```
┌─────────────────────────────────┐
│ ● Открыто          дедлайн 21:00│  ← бейдж + мета
│ Кто больше откусит икры?        │  ← display-md
│ ─────────────────────────────── │
│ [ Жених  ×2.5 ] [ Невеста ×1.8]│  ← исходы-кнопки
└─────────────────────────────────┘
```

- Фон: `felt-800`, бордер: `1px solid felt-600`
- Выбранный исход: бордер `casino-red-600`, лёгкое красное свечение
- Коэффициент: `gold-400`, жирный

### Блок баланса

- Крупная сумма (`amount`) в `gold-400`
- Подпись «Ваш баланс» — `body-sm`, `cream-200`
- Декоративная иконка фишки (красно-золотая) слева от суммы
- Кнопка «Пополнить» — primary, всегда рядом или под балансом

### Формы

- Фон инпута: `felt-900`, бордер `felt-600`, focus: `ring-casino-red-600`
- Placeholder: `cream-400`
- Ошибка: бордер `error` + текст `body-sm` под полем
- Поля суммы: numeric keyboard на мобильном (`inputmode="numeric"`)

### Навигация (гость)

Нижняя tab-bar на `felt-800`:
- Главная | События | Пополнить | История
- Активный таб: иконка + текст `casino-red-500`
- Неактивный: `cream-400`

### Админ-панель

- Фон светлее гостевого: `cream-50` / `#F5F0EB` — для длительной работы
- Sidebar или top-nav: `felt-900` с белым текстом
- Таблицы: чередование строк `white` / `felt-900/5`
- Действия подтверждения — `casino-green-500`, отклонение — `error`
- Pending-пополнения: жёлтый/оранжевый акцент `warning`, счётчик в sidebar

## 5. Экраны и паттерны

### Главная (гость)
1. Шапка: логотип + имя гостя
2. Блок баланса (золото + красная кнопка пополнения)
3. Список открытых событий (карточки)
4. Баннер «Ожидает подтверждения» если есть pending-пополнение (`warning`)

### Карточка события
1. Заголовок + описание
2. Сетка исходов (2 колонки на мобильном)
3. Поле суммы ставки + пресеты (100 / 500 / 1000 ₽)
4. Sticky footer с кнопкой «Поставить N ₽»

### Пополнение
1. Реквизиты в копируемом блоке (иконка «скопировать»)
2. Уникальный код `BRD-XXXX` — крупно, `gold-400`, с кнопкой копирования
3. Пошаговая инструкция (1–2–3)
4. Форма заявки

### История
- Группировка по дате
- Тип операции: цветная точка (зелёный = выигрыш/пополнение, красный = ставка)
- Сумма: `+` зелёный, `−` красный

### Пустые состояния
- Иллюстрация или иконка фишки
- Текст: «Пока нет открытых событий» / «Сделайте первую ставку»
- CTA ведёт к действию

## 6. Иконки и иллюстрации

- **Набор:** [Lucide Icons](https://lucide.dev) — единый stroke-width 1.5–2
- **Размеры:** 20px в навигации, 24px в кнопках, 16px в бейджах
- Декоративные элементы: стилизованные фишки, масти (♠ ♥ ♦ ♣) — только как лёгкий фоновый паттерн с opacity 3–5%, не перегружать
- Фото и аватары гостей — не в MVP; инициалы в круге на `felt-700`

---

## 7. Анимации и микровзаимодействия

- Длительность: 150–250ms, easing `ease-out`
- Нажатие кнопки: `scale(0.98)` на active
- Появление карточек: лёгкий fade + slide up 8px
- Успешная ставка: короткая вибрация (если API доступен) + toast «Ставка принята»
- Выигрыш (фаза 2): конфетти в цветах red/green/gold — умеренно, 1–2 сек
- **Не использовать:** бесконечные мигающие баннеры, агрессивный slot-machine UX

---

## 8. Запрещённые элементы (Anti-patterns)

- Не использовать неоновые цвета (#00FF00, #FF00FF) и «Лас-Вегас 2005»
- Не смешивать Material Design и iOS-нативные паттерны в одном экране
- Не ставить красный и зелёный рядом без нейтрального разделителя (риск для дальтоников)
- Не использовать шрифты без кириллицы (Roboto Condensed без проверки, системный San Francisco для русского UI)
- Не делать мелкие кнопки (< 44px) — гости будут с телефона, часто в движении
- Не прятать баланс и статус пополнения глубже двух тапов
- Не использовать чисто красный фон для больших областей — красный только акцент
- Не перегружать экран коэффициентами и текстом; одно событие — один фокус

---

## 9. Логотип и название

- **Название:** Bridino — в Playfair Display, `casino-red-600` или `gold-400` на тёмном фоне
- **Вариант для светлого фона:** `felt-900`
- Можно добавить маленькую красную фишку (круг с буквой B) слева от слова
- Favicon: красная фишка на зелёном круге

## 10. Чеклист для разработчика

Перед сдачей экрана проверить:

- [ ] Все тексты на русском, шрифты отображают «ё», «й», кавычки-ёлочки «»
- [ ] Контраст текста достаточный на felt-фоне
- [ ] Кнопки ≥ 48px, отступы между интерактивными зонами ≥ 8px
- [ ] Суммы форматируются как `1 000 ₽`
- [ ] Статусы дублируются текстом, не только цветом
- [ ] Primary-действие — красное, успех/выигрыш — зелёное, деньги — золотое
- [ ] Экран читаем на экране 375px (iPhone SE) без горизонтального скролла
