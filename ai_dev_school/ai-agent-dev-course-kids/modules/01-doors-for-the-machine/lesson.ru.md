# Занятие 1 — Двери для машины

## Для тебя

Знаешь что? Машина живёт в комнате без окон. Она видит только то, что лежит внутри её комнаты. Но у комнаты можно открыть **дверь** — и тогда машина сможет заглянуть в одну-единственную вещь снаружи: список твоих любимых зверей, например. Решаешь, какую дверь открыть, ты (вместе со взрослым). Сегодня мы откроем одну дверь — «только смотреть».

## Карточка Идеи

> Машина должна знать про: мои любимые ______
> Дверь ведёт к: списку под названием ______
> Эта дверь «только смотреть» 👀 — менять и стирать нельзя

## Для взрослого

1. Это первое занятие, где машина получает «суперсилу». Оно идёт сразу после Занятия 0. Всё остаётся локальным: никаких аккаунтов, интернета и паролей.
2. Создайте отдельную папку `facts` внутри папки курса (например, `~/kid-ideas/facts`) и вместе с ребёнком запишите в файл `animals.txt` три любимых зверя и по одному факту о каждом (например: «слон — самый большой»). Печатаете вы.
3. Откройте «дверь» — подключите к Claude Code сервер MCP «Filesystem», ограниченный только этой папкой: `claude mcp add --transport stdio kidfacts -- npx -y @modelcontextprotocol/server-filesystem ~/kid-ideas/facts`. Затем сделайте её «только смотреть»: в настройках запретите (deny) инструменты записи этого сервера — их список виден в `/mcp` (что-то вроде `write_file`, `edit_file`, `move_file`). Проверьте имена по README сервера — они могут измениться.
4. Прочитайте вслух, что Claude Code просит разрешить. Попросите: «Загляни в дверь kidfacts и скажи, какой зверь из списка самый большой». Пусть ребёнок увидит ответ.
5. Закройте дверь (`claude mcp remove kidfacts` или выключите в `/mcp`) и задайте тот же вопрос. Машина скажет, что не видит список. Итог для ребёнка: дверь решает, что машина может видеть.
6. Если ставить сервер не хочется, проведите занятие «на бумаге»: вы — «дверь», ребёнок задаёт вопросы машине (вам), а вы отвечаете только тем, что написано на листе со списком. Смысл тот же.

## Покажи и расскажи

Спросите: «Какую дверь мы открыли? Что машина могла через неё делать — а чего не могла?» Ребёнок должен сказать своими словами: «только смотреть, ничего не менять».
