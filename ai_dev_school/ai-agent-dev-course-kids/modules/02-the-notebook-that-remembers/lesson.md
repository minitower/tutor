# Session 2 — The Notebook That Remembers

## For You

When you close the machine and open it again, it **forgets everything** — every morning it wakes up with a blank page. Want it to remember your favorite things? Then it needs a **notebook**: the machine reads it every time it wakes up. But there's an important rule: we only write fun favorites in the notebook. Secrets — never.

## Idea Card

> Please remember: my favorite color is ______
> Please remember: I love ______
> We never write in the notebook: where I live, my school, passwords and secrets ✋

## For the Grown-Up

1. The notebook is an ordinary `CLAUDE.md` file in the course folder (for example `~/kid-ideas/CLAUDE.md`): Claude Code reads it at every start in that folder. So this is a real, working "memory".
2. First talk through the secrets rule: full name, address, school, phone, passwords, other people's names — **we don't write those**. We write favorites only: colors, animals, food, games. Check the card together before writing anything.
3. Put the card's lines into the file, for example: "My favorite color is green. I love kittens." You type, reading aloud.
4. "A new day": close Claude Code and open it again (a blank page). Without mentioning the color or animal, ask: "Make me a page I'll like." Let the kid notice that the machine picked green and kittens on its own.
5. "Forgetting on purpose": erase one line from the notebook, reopen and ask for the same page again. The machine no longer knows about kittens. The kid is the boss of the notebook: they decide what stays in it.
6. No real personal data in the notebook — not even "just in case". If the kid wants to write a secret, praise them for saying it and explain why it stays in their head.

## Show & Tell

Ask: "What did we write in the notebook? What do we never write there — and why?" The key is that the kid names at least one kind of secret and a reason.
