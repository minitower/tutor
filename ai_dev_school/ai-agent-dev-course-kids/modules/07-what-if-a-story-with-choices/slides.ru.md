# С возвращением! 👋

В прошлый раз ты узнал(а) важную вещь:

**машина делает только то, что ты ей на самом деле сказал(а).**

Сегодня будет кое-что новое — **истории!**

---

<!-- Slide 2 -->
## Главная идея сегодня

История не обязана идти только **одним** путём.

Ты сделаешь историю, в которой
**читатель сам выбирает, что будет дальше.**

---

<!-- Slide 3 -->
## История может разветвляться!

Ты находишь во дворе странную дверь.

```
        История начинается
         /              \
   Выбор А             Выбор Б
 «Открыть её»        «Постучать»
      |                   |
Комната полна        Маленький дракон
 прыгучих мячей!      говорит «привет»!
```

Два выбора. Два разных финала!

---

<!-- Slide 4 -->
## Что мы делаем сегодня

Маленькую историю на экране, у которой есть:

- **начало**
- **два варианта выбора**
- свой **финал** для каждого варианта
