# Занятие 4 — Что если...? История с выбором

## Для тебя

Истории не обязаны идти только одним путём. Сегодня ты напишешь
маленькую историю, в которой тот, кто её читает, сам выбирает, что
будет дальше — как книжка «выбери своё приключение», только сделанная
тобой.

## Карточка Идеи

> История начинается: ______.
> Если выбрать ______, то происходит ______.
> Если выбрать ______, то происходит ______.

(Пусть будет только два варианта выбора и короткий итог для каждого —
это не должна быть целая книга.)

## Для взрослого

1. Заполните карточку вместе — этому занятию помогает, если сначала
   проговорить всё вслух, а уже потом записывать.
2. Инструкция для Claude Code: *«Сделай простую локальную веб-страницу,
   которая рассказывает эту короткую историю: [начало истории]. Потом
   покажи две кнопки: „[выбор 1]“ и „[выбор 2]“. При нажатии на каждую
   показывается её итог: [итог 1] / [итог 2].»*
3. Подтвердите, проговорите, откройте результат — а потом пройдите
   вместе по обоим вариантам выбора.

## Покажи и расскажи

Пусть ребёнок выберет одну из двух веток, чтобы показать кому-то ещё, и
попросит этого человека угадать, что могло бы произойти при *другом*
выборе, прежде чем показать ему на самом деле.
