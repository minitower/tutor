Где ИИ в «Slot» и какой уровень выбрать

Начинайте с самого простого уровня. Агент — когда задачу нельзя расписать заранее.

Анатомия запроса

import anthropic

client = anthropic.AsyncAnthropic()      # ключ из ANTHROPIC_API_KEY, только на бэкенде

response = await client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    system="Ты помощник барбершопа «Борода». Отвечай коротко и только про услуги и запись.",
    messages=[{"role": "user", "content": "Сколько стоит стрижка бороды?"}],
)
answer = next(b.text for b in response.content if b.type == "text")
print(response.usage.input_tokens, response.usage.output_tokens)
  • system — роль и правила; messages — диалог; max_tokens — потолок длины ответа
  • usage — сколько токенов потрачено: это ваш счёт

Токены и стоимость

Платите за вход (промпт, история, документы) и выход (ответ и размышления модели).

МодельВход, $ за 1 млн токеновВыход, $ за 1 млн токенов
Claude Opus 5.5420
Claude Sonnet 5.5210
Claude Haiku 4.515
1 000 запросов в день × (2 000 токенов входа + 300 выхода) на Opus 5.5 = 8 $ + 6 $ = ~14 $ в день, ~420 $ в месяц.

Цены — на октябрь 2026; проверяйте актуальные на сайте провайдера.

Как платить меньше

  1. Кэш промпта неизменная часть (системный промпт, прайс, FAQ) — повторное чтение в разы дешевле
  2. Контекст не отправляйте всю историю и все документы — только нужное
  3. Длина ограничение длины ответа и просьба отвечать кратко
  4. Effort для простых задач — ниже, для сложных — выше
  5. Batch фоновые задачи пакетом — примерно за полцены
  6. Метрика стоимость выполненной задачи, а не одного запроса

Стриминг: ответ по мере генерации

from fastapi.responses import StreamingResponse

@app.post("/api/assistant")
async def assistant(q: Question):
    async def events():
        async with client.messages.stream(
            model="claude-opus-5-5", max_tokens=1024,
            system=SYSTEM, messages=[{"role": "user", "content": q.text}],
        ) as stream:
            async for text in stream.text_stream:
                yield f"data: {json.dumps({'text': text})}\n\n"
    return StreamingResponse(events(), media_type="text/event-stream")
  • Ответ за 6 секунд, который начинает печататься через 1 секунду, ощущается быстрым
  • Server-Sent Events (Модуль 4): простой поток от сервера к браузеру

Цикл инструментов

messages = [{"role": "user", "content": user_text}]
for _ in range(MAX_STEPS):                       # предел шагов — защита от зацикливания
    response = await client.messages.create(
        model="claude-opus-5-5", max_tokens=4096,
        system=SYSTEM, tools=tools, messages=messages)
    if response.stop_reason != "tool_use":
        break
    messages.append({"role": "assistant", "content": response.content})
    results = []
    for block in response.content:
        if block.type == "tool_use":
            output = await run_tool(block.name, block.input, user=current_user)
            results.append({"type": "tool_result", "tool_use_id": block.id, "content": output})
    messages.append({"role": "user", "content": results})

SDK умеет делать этот цикл за вас (tool_runner), но один раз стоит написать его руками.

Когда RAG не нужен

Данные помещаются в контекст

Прайс и FAQ одного мастера — 2–3 тысячи токенов. Положите их в системный промпт целиком и включите кэширование — проще и точнее любого поиска.

RAG нужен

Документов тысячи, или они часто меняются. Тогда — гибридный поиск (полнотекстовый + векторный), ссылки на источник, переиндексация при изменении.

Сначала проверьте, помещаются ли данные в контекст.

Архитектура ИИ-функции

Месячный бюджет с алертом: один зацикленный скрипт может сжечь его за ночь.

Без eval любое «улучшение промпта» — это мнение.

Наблюдаемость и учёт стоимости

  • На каждый вызов: функция, модель, токены входа и выхода, кэш, задержка, stop_reason
  • Дашборд: стоимость по функциям и пользователям, p95 задержки, доля отказов
  • Алерт на рост стоимости — так ловят зацикливание и злоупотребления
  • Примеры диалогов (с согласия и без персональных данных) — из них растёт eval-набор

Лабораторная работа

  1. Ассистент записи: намерение → find_free_slots → варианты; запись — только после «Подтвердить»
  2. Стриминг через SSE; прайс и FAQ — в кэшируемом системном промпте
  3. Лимиты: запросов на пользователя, шагов цикла, месячный бюджет
  4. Eval-набор из 30 запросов: точность и стоимость одного запроса
  5. С агентом: агент пишет цикл и прогон eval; вы ломаете ассистента инъекцией и закрываете то, что прошло

Результат

  • Оценка стоимости в месяц для 10 и для 1 000 мастеров
