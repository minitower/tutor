Python: FastAPI

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class BookingCreate(BaseModel):     # типы = валидация + OpenAPI
    slot_id: int
    client_name: str
    phone: str

@app.post("/api/bookings", status_code=201)
async def create_booking(data: BookingCreate):
    booking = await book_slot(data)       # бизнес-логика
    if booking is None:
        raise HTTPException(409, "slot_taken")
    return booking

Документация /docs генерируется сама. Лучший выбор для API и ИИ/ML-сервисов.

Python: Django и альтернативы

Django

«Батарейки в комплекте»: ORM, миграции, админка за 10 строк, авторизация, формы. API — через DRF или Django Ninja.

Flask

Минимализм: только роутинг и запросы, остальное подключаете сами.

Litestar

Как FastAPI, но больше встроенного: DI, кэш, плагины ORM.

Django — когда нужна админка «вчера». Меньше свободы, больше соглашений — новичку проще не ошибиться.

Rust

async fn create_booking(Json(data): Json<BookingCreate>) -> impl IntoResponse {
    match book_slot(data).await {
        Some(b) => (StatusCode::CREATED, Json(b)).into_response(),
        None => (StatusCode::CONFLICT, "slot_taken").into_response(),
    }
}

Плюсы

Axum, Actix Web: максимум скорости, безопасность памяти без сборщика мусора; компилятор ловит гонки данных и null.

Цена

Высокий порог входа, медленная компиляция. Брать для горячих участков, прокси, CPU-нагрузки.

Модели конкурентности

Как обслужить 10 000 клиентов, которые ждут ответа от БД?

ЯзыкМодельСуть
PythonGIL + asyncioОдин поток Python за раз; async переключается на время ожидания I/O
Node.jsEvent loopОдин поток, всё I/O неблокирующее
GoГорутиныТысячи лёгких потоков, рантайм раскладывает их по ядрам
RustTokioКак asyncio, но без GIL, на всех ядрах
JavaВиртуальные потокиПишем блокирующий код, JVM делает его дешёвым

Что на самом деле даёт async

  • Async ускоряет ожидание, а не вычисления: тяжёлый расчёт в async-функции блокирует всех
  • Python: CPU-задачи → отдельные процессы, очередь или расширение на Rust/C

Авторизация

Сессии

ID сессии в cookie, данные на сервере. Классические веб-приложения.

JWT

Подписанный токен с данными у клиента. API, мобильные клиенты, микросервисы.

OAuth / OIDC

«Войти через Google / Яндекс / Telegram». Не храните пароли сами.

  1. Никогда пароли открытым текстом — только хэш (argon2, bcrypt)
  2. Всегда токены с коротким сроком жизни; права проверяет сервер

Агенты

Популярные стеки агенты пишут заметно лучше.

Структура API «Slot» на FastAPI

app/
  main.py             # приложение, роутеры
  api/bookings.py     # только HTTP
  services/booking.py # бизнес-логика
  db/models.py        # таблицы
  db/repo.py          # запросы к БД
  schemas.py          # вход и выход API
migrations/           # Alembic
tests/                # pytest, TC-xx
HTTP: api/
↓
Логика: services/
↓
Данные: db/

Логику можно тестировать без HTTP и БД — и агенту проще менять один слой, не задевая другие.

Лабораторная работа

  1. Реализуйте API «Slot» на FastAPI + PostgreSQL по OpenAPI из Модуля 1
  2. Миграции через Alembic, тесты на pytest по тест-кейсам
  3. Защита от двойной записи — уникальный индекс в БД
  4. Повторите один эндпоинт на Go (или Rust) — сравните
  5. С агентом: дайте агенту OpenAPI + тест-кейсы, попросите реализовать через тесты; проверьте, что он не выдумал полей, которых нет в контракте

Результат

  • Рабочее API с миграциями и тестами
  • Тот же эндпоинт на втором языке
  • Заметки сравнения: объём кода, скорость написания, инструменты, время ответа, память
  • Список «выдумок» агента и как вы их поймали

Любой бэкенд: роутинг, валидация, авторизация, логика, данные, фон. Python — скорость разработки и ИИ; Go — простая производительность; Rust — максимум; Node — один язык; Java/C# — энтерпрайз. Async ускоряет ожидание, не вычисления.
