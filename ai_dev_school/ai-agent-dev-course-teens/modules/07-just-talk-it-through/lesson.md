# Module 7 — Just Talk It Through

## Big idea

Not everything needs a written plan. For small stuff, or when you're
just exploring an idea and don't know exactly what you want yet, talking
it through step by step — correcting as you go — is faster than writing
a doc first.

## Why it matters

Knowing *when* to skip the paperwork is as important as knowing how to
write it. Module 3 taught you the written-plan approach; this module is
about recognizing when that would just be overhead.

## Hands-on task

1. Pick a small feature — ideally similar in size to the one you built in
   Module 3.
2. Build it purely conversationally this time: no written plan, just
   back-and-forth, correcting direction as you notice things drifting.
3. Keep rough track of how many messages/turns it took.

## Checkpoint

Compare this to your Module 3 result:
- Which took more effort overall?
- Which result would you trust more for something you plan to keep
  working on for months? Which was fine for something quick and
  disposable?
- Is there a size of task where you can feel the "should've written this
  down" moment happen mid-session?

## Supervisor note

Standard supervision. This module works best right after Module 3, while
that comparison is still fresh — don't let too much time pass between
them.
