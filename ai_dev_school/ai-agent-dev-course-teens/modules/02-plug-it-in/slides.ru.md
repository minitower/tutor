## Агент живёт в пузыре

- Он видит папку проекта — и всё
- Таблица очков, данные бота, календарь клуба — для него не существуют
- Можно копировать данные в чат руками... каждый раз
- Лучше: дать ему **безопасный вход** к нужному

---

<!-- Slide 4 -->

## MCP — это USB для ИИ

- **Model Context Protocol** — открытый стандарт, как агент подключается к внешним инструментам и данным
- Раньше: каждая пара «программа × сервис» — своя интеграция
- Теперь: пишешь сервер один раз — подключается любой агент
- Сообщения идут в формате JSON-RPC (обычный JSON)

---

<!-- Slide 5 -->

## Три роли

- **Host** — программа с ИИ (Claude Code, редактор)
- **Client** — «порт» внутри host, по одному на сервер
- **Server** — твоя маленькая программа с инструментами
- Связь: локально (**stdio**, сервер — дочерний процесс) или по сети (**HTTP**)

---

<!-- Slide 6 -->

## Что может дать сервер

- **Tools** — функции, которые вызывает агент (`top_scores`, `add_note`)
- **Resources** — данные, которые можно прочитать (файл, схема)
- **Prompts** — заготовки запросов, которые запускаешь ты
- У инструмента есть **имя, описание и типы аргументов** — по ним агент решает, когда его вызвать

<!-- Slide 7 -->

## Подключаем сервер

```bash
claude mcp add --transport stdio scores -- python scores_server.py
claude mcp list        # Connected / Failed
claude mcp remove scores
```

Общий файл проекта — `.mcp.json` (без секретов!). Инструмент называется `mcp__scores__top_scores` — по такому имени пишутся правила разрешений.

---

<!-- Slide 8 -->

## Свой сервер за 10 строк

```python
# scores_server.py   (pip install mcp)
import json
from mcp.server.mcpserver import MCPServer   # older mcp 1.x: from mcp.server.fastmcp import FastMCP

mcp = MCPServer("scores")
SCORES = json.load(open("scores.json"))       # {"ana": 120, "bo": 95, "cy": 150}

@mcp.tool()
def top_scores(n: int = 3) -> list[str]:
    """Return the top n players and their scores (read-only)."""
    best = sorted(SCORES.items(), key=lambda kv: kv[1], reverse=True)[:n]
    return [f"{name}: {score}" for name, score in best]

if __name__ == "__main__":
    mcp.run()
```

Описание и типы — это то, что видит агент. Один узкий инструмент лучше десяти общих.

## Подключить = доверять

- Сервер — **программа на твоём компьютере**: она может всё, что можешь ты
- Описание инструмента читает модель — вредное описание может её подтолкнуть
- Результат инструмента — ненадёжный текст: в нём может быть спрятана «инструкция» (Модуль 12)
- Чужая команда `npx -y ...` из интернета — это запуск чужого кода

<!-- Slide 10 -->

## Чек-лист «можно подключить?»

- ☐ Я знаю, кто написал сервер, и я прочитал(а) его код (или это официальный пример)
- ☐ Доступ **только на чтение**, данные тестовые
- ☐ Никаких паролей и токенов от личных аккаунтов
- ☐ Версия зафиксирована, а не «последняя»
- ☐ Я знаю имена его инструментов и запретил(а) лишние
