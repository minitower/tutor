# Модуль 7 — Единый визуальный стиль

## Главная идея

Если ты нигде по-настоящему не записал свои цвета, шрифты и отступы,
агенту приходится угадывать их каждую сессию заново — и каждый раз
он будет угадывать по-разному. Решение: сделай файл «таблицы стилей» с
реальными значениями (настоящие коды цветов, настоящие названия
шрифтов, настоящие числа отступов) и скажи агенту всегда использовать
его вместо того, чтобы выбирать самому.

```css
:root {
  --color-background: #14161a;
  --color-accent: #ffb703;
  --font-heading: "Poppins", sans-serif;
  --space-unit: 8px;
}
```

Именно конкретные значения делают результат единообразным. «Сделай
покруче и посовременнее» — это ровно тот тип инструкции, который каждый
раз выглядит по-разному.

## Почему это важно

Проект, построенный страница за страницей без этого, в итоге выглядит
так, будто его сшили из пяти разных проектов. Это один файл, который
предотвращает это раз и навсегда, на весь оставшийся курс.

## Практическое задание

1. Сделай настоящий файл таблицы стилей для своего проекта с реальными
   кодами цветов, шрифтом и значениями отступов.
2. Добавь короткую заметку в файл инструкций своего проекта, говорящую
   агенту: «всегда проверяй этот файл перед тем, как стилизовать
   что-либо, и не вводи новые цвета/шрифты/отступы за его пределами».
3. В одной сессии построй одну страницу/экран, используя только этот
   файл как руководство по стилю.
4. В **совершенно отдельной, свежей сессии** построй вторую, другую
   страницу/экран — с тем же правилом.
5. Положи обе рядом.

## Чекпоинт

- Действительно ли эти две страницы выглядят так, будто принадлежат
  одному проекту?
- Попробуй один раз *без* указания агенту на файл стилей — просто
  «сделай красиво». Насколько по-другому выглядит этот вариант?

## Заметка для куратора

Стандартный уровень присмотра. Приятный модуль для наблюдения —
сравнение рядом наглядно доказывает мысль без всяких объяснений.
