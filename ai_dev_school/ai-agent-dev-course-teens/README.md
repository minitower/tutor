# Build With AI: An Agentic Coding Course for Teens (14–17)

A hands-on course that teaches the same core skill as the adult version
of this course — directing an AI coding agent (Claude Code) well enough
to build real things — but paced, framed, and supervised for teenage
beginners to intermediate coders instead of professional developers.

This is the teen counterpart to [../ai-agent-dev-course](../ai-agent-dev-course/README.md).
Same underlying ideas (writing things down before building, planning
before executing, testing, reviewing critically, working with more than
one agent), reframed with metaphors and projects that make sense to a
14–17 year old, and with real supervised use of the actual tool instead
of a simulation.

## Who this is for

Teens 14–17 who can already write *some* code (even just basic
Python/JS/HTML — a semester of intro programming or equivalent
self-teaching is enough) and want to learn how to work with an AI coding
agent effectively, not just ask it to "make me an app" and hope. No
professional experience assumed. Reads more like a strong intro coding
elective than a children's activity book — teens generally want to be
taken seriously, not talked down to.

## Format

- 16 modules (Module 0 through Module 15), ~45–90 minutes each
- Every module = a short concept explanation + a real hands-on task with
  Claude Code + a reflection/checkpoint
- **Supervised, real-tool use throughout.** Read
  [SUPERVISOR-GUIDE.md](SUPERVISOR-GUIDE.md) before Module 0 — it covers
  sandboxing, permission settings, and what a supervising adult should
  watch for. This is not optional scaffolding; it's the safety model the
  whole course assumes.
- Projects are things a teen would actually want to build: a personal
  site, a small game, a Discord/Telegram bot, a tool for a school club —
  pick one at the start and carry it through most modules so the
  techniques compound instead of resetting each time

## How this differs from the adult course

| | Adult course | Teen course |
|---|---|---|
| Assumed background | Professional dev experience | Some intro coding, no pro experience |
| Framing | Direct, technical | Same technical substance, more scaffolding and concrete metaphors |
| Supervision | None assumed | Built-in supervisor guide, sandboxed setup required |
| Scope examples | APIs, refactors, CI/CD | Personal projects: sites, games, bots, school tools |
| Module count | 15 | 16 (adds Module 0: what an agent actually is) |

## Learning outcomes

By the end, a teen can:
1. Explain what an AI coding agent actually does when it "writes code for
   you" (it's not magic, and it's not always right)
2. Write clear enough instructions/specs that the agent doesn't have to
   guess what they meant
3. Catch the agent's mistakes instead of blindly trusting the output
4. Use planning, testing, and review as habits, not just something adults
   tell them to do
5. Talk honestly about when and how they used AI help — for a class
   project, a portfolio piece, or just their own understanding of what
   they actually built themselves

## Open questions to settle before running this

- Solo (self-paced with a parent/mentor checking in) or a small group
  class setting?
- Which project track do most participants want — website, game, bot, or
  open choice? (Affects how concrete to make the module examples)
- Is there a showcase/presentation moment planned for the capstone, or is
  it just for the participant's own portfolio?
