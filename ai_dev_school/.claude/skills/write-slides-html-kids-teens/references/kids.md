# Kids theme (ages 7-8) — `ai-agent-dev-course-kids/assets/deck.css`

## Palette

```
--bg:       #fff6e9   warm cream (not stark white — friendlier)
--bg-2:     #ffffff
--fg:       #3a2e5c   soft dark plum (not harsh black)
--fg-dim:   #7a6ea3
--accent:   #ff7a50   coral — "let's go" / primary actions
--accent-2: #3dd68c   green — yay / success / "she built it"
--accent-3: #ffc93c   sunny yellow — idea spark, sparkle bits
--accent-4: #4ea8ff   sky blue — secondary, "watching/looking"
--pink:     #ff6fa8   extra playful accent — stars, emphasis
--radius:   28px       (big and chunky everywhere)
--shadow:   0 10px 0 rgba(58,46,92,.08), 0 18px 30px rgba(58,46,92,.10)
```

Cards/buttons get a soft drop shadow (`--shadow`) — unlike the flat
adult/teens dark themes, kids UI should feel slightly tactile/poppable.
Background has a subtle two-tone polka-dot texture (`radial-gradient`
dots in coral and blue at 10% opacity) so it's never a flat rectangle.

No web fonts — system font stack, leaning on weight (800) and size
instead of a novelty typeface (avoid Comic-Sans-style choices; bold +
big + rounded corners reads as friendly without hurting legibility).

## Default slide shape

Unlike the adult/teens decks, kids slides default to **centered**, not
left-aligned (`.slide { align-items:center; text-align:center; }`) —
content here is "one idea per slide," not bulleted lists. If a slide
genuinely needs a bulleted list, `<li>` already renders as its own small
shadowed card (see deck.css `.slide li`), not a plain bullet.

## Components

- **`.mascot-wrap` / `.mascot-wrap.small`** — wrapper for the robot
  mascot SVG (see below). Use the full-size version once per session
  (title + finale), `.small` everywhere else it appears.
- **`.idea-card`** — the fill-in-the-blank card. Dashed blue border,
  white background. Put `<p class="line">` rows inside, with
  `<span class="blank"></span>` for each blank to fill in:
  ```html
  <div class="idea-card">
    <p class="line">Меня зовут <span class="blank"></span>.</p>
  </div>
  ```
- **`.icon-row`** — a horizontal row of small labeled icons (e.g. "what
  we're making today"). Each `.item` is an SVG + one short label.
- **`.kid-cards`** — 2-3 chunky shadowed cards with an icon, a short
  title, and a sentence — the kids equivalent of the adult `.trio`.
- **`data-layout="celebrate"`** — the payoff/finale slide type. Gradient
  `<h1>` shifts to the green/yellow/pink range (success colors, not the
  coral/blue "let's go" range used elsewhere) and expects a `.confetti`
  div for the falling-shapes animation:
  ```html
  <section class="slide" data-layout="celebrate">
    <div class="confetti" id="confetti"></div>
    <h1>У тебя получилось! 🌟</h1>
    ...
  </section>
  ```
  The confetti pieces are generated by a small inline `<script>` at the
  bottom of the page (see `modules/00-meet-the-idea-machine/slides.html`
  for the exact snippet) — copy that script block as-is, it reads
  `#confetti` and needs no per-slide changes.

## Icon/illustration library

All use CSS vars, sized via explicit `width`/`height` (not just
`max-width` — see the SKILL.md gotcha). Reuse these rather than drawing
new ones for a new module unless the module genuinely needs a new
concept (e.g. a paint palette for "Pick Your Own Colors").

**Mascot** (the "Idea Machine" — a screen-and-keyboard robot):
```svg
<svg viewBox="0 0 200 220" xmlns="http://www.w3.org/2000/svg">
  <line x1="100" y1="18" x2="100" y2="38" stroke="var(--accent-4)" stroke-width="6" stroke-linecap="round"/>
  <path d="M100 6 l8 14 h-16 z" fill="var(--accent-3)"/>
  <rect x="30" y="38" width="140" height="110" rx="24" fill="var(--card)" stroke="var(--accent-4)" stroke-width="7"/>
  <circle cx="75" cy="90" r="10" fill="var(--fg)"/>
  <circle cx="125" cy="90" r="10" fill="var(--fg)"/>
  <path d="M70 112 q30 24 60 0" fill="none" stroke="var(--accent-2)" stroke-width="7" stroke-linecap="round"/>
  <rect x="46" y="162" width="108" height="42" rx="14" fill="var(--card)" stroke="var(--pink)" stroke-width="7"/>
  <circle cx="70" cy="183" r="5" fill="var(--pink)"/>
  <circle cx="100" cy="183" r="5" fill="var(--pink)"/>
  <circle cx="130" cy="183" r="5" fill="var(--pink)"/>
</svg>
```

**Lightbulb** (idea): circle outline + rays + zig-zag base, `--accent-3`.
**Star**: single `<path>` 5-point star, `--pink`.
**Tag** (name/label): pennant-shape path + white hole punch, `--accent`.
**Eye** (watching/looking): almond `<path>` + filled pupil circle, `--accent-4`.
**Gear/spark** (machine working): ringed circle with 8 radiating spokes,
`--accent-2` — reads a bit like a sun/flower at small sizes, which is
fine (still lands as "something is happening/energetic").
**Trophy/badge** (finale): filled circle + checkmark + small pennant base,
`--accent-3` circle / `--pink` base.
**Browser mockup** (showing off a finished page): rounded rect + colored
title bar with 3 dots + centered placeholder text — use this whenever a
slide needs to show "here's the thing you built."

Full working examples of every one of these are already in
`modules/00-meet-the-idea-machine/slides.html` — copy from there rather
than retyping from this description.
