# Список научных конференций (ЛР2, Вариант 5)

Сайт на Django для публикации научных конференций: темы, место и период проведения, описание, условия участия. Пользователи регистрируются, записываются на конференции как докладчики (свои заявки можно редактировать и удалять) и оставляют отзывы с оценкой. Администратор через Django-admin отмечает, рекомендован ли доклад к публикации; на сайте есть общая таблица участников по всем конференциям.

## Стек
- Python 3, Django 3.2
- PostgreSQL 16+ в Docker (см. `docker-compose.yml`)
- Bootstrap 5 (через CDN, без сборки статики)

## Модели (`conferences/models.py`)
- `Topic` — тематика конференции.
- `Conference` — название, тематики (M2M), место и его описание, период, описание, условия участия.
- `Registration` — заявка пользователя на выступление (тема доклада), плюс `recommended_for_publication` — редактируется только через Django-admin.
- `Review` — отзыв: рейтинг 1–10, текст, автор, привязка к конференции.

## Реализованный функционал
- Регистрация/вход/выход (`django.contrib.auth` + свой `signup`).
- Список конференций с пагинацией, поиском по названию и фильтром по теме/датам.
- Запись на выступление, редактирование и удаление своей заявки.
- Отзывы с рейтингом.
- Публичная таблица всех участников по конференциям (с пагинацией).
- Разграничение прав в интерфейсе: обычный пользователь видит и правит только свои заявки/отзывы, `is_staff` — видит отметку в шапке и может удалять чужие.

## Требования задания (на максимальный балл)
- Стилизация интерфейса CSS-библиотекой — Bootstrap 5.
- Пагинация списков (конференции, участники).
- Фильтрация и поиск по конференциям (тема, диапазон дат, текст в названии).
- Разграничение прав администратора и пользователя в клиентском интерфейсе (`is_staff`), а не только через Django-admin.

## Предпосылки
- Docker Desktop запущен.
- `venv/` уже создан и заполнен (`requirements.txt`: Django 3.2, psycopg2-binary). Если venv нет или сломан:
  ```
  python -m venv venv
  venv\Scripts\pip install -r requirements.txt
  ```

## 1. Поднять PostgreSQL
```
docker compose up -d
```
Контейнер `conferences_postgres`, БД `conferences_db` на `localhost:5439` (см. `docker-compose.yml` / `conferences_site/settings.py`).

Проверить, что контейнер жив:
```
docker ps --filter name=conferences_postgres
```

## 2. Активировать venv
```
venv\Scripts\activate
```

## 3. Миграции (нужно только после изменений в models.py)
```
python manage.py migrate
```

## 4. Суперпользователь
Один уже создан (`admin`, staff+superuser). Если нужен новый или пароль забыт:
```
python manage.py createsuperuser
```

## 5. Запуск сервера
```
python manage.py runserver
```
- Список конференций: http://127.0.0.1:8000/
- Регистрация: http://127.0.0.1:8000/signup/
- Все участники: http://127.0.0.1:8000/participants/
- Админка: http://127.0.0.1:8000/admin/

## Остановить
- Сервер: `Ctrl+C`.
- Postgres: `docker compose down` (данные останутся в volume `conferences_pgdata`; добавить `-v`, чтобы стереть их вместе с контейнером).
