# Спека: Основное задание ЛР2 — Вариант 5, список научных конференций

Источник: `../Main task.html`. Отдельный Django-проект, не связан с practice_2_1/2_2/2_3.

## Стек
Django 3.x, PostgreSQL в Docker (новый контейнер, образ `postgres:latest`, порт хоста `5439:5432`), MVC + шаблоны Django, Bootstrap/Tailwind для стилизации.

## Docker (для main_task/ только)
`docker-compose.yml` в `main_task/`: один сервис `conferences_postgres`, `POSTGRES_DB=conferences_db`, volume для персистентности. Поднимается только когда дойдём до кода — сейчас не создаём.

## Модель данных (предложена мной по функциональному описанию — вариант 5 не даёт готовую ER-схему, нужно подтвердить)

- `Topic` — name
- `Conference` — title, topics (M2M Topic), venue_name, venue_description, start_date, end_date, description, participation_terms
- `Registration` — conference (FK), user (FK settings.AUTH_USER_MODEL), talk_title, created_at, recommended_for_publication (nullable bool, редактируется только в Django-admin)
- `Review` — conference (FK), author (FK user), rating (1–10, validators), text, created_at

## Функционал (из задания, вариант 5)
1. Регистрация новых пользователей (стандартный Django auth, либо своя форма на `UserCreationForm`).
2. Просмотр конференций (список + пагинация + фильтр/поиск — по topics/дате, обязательно для макс. балла) и регистрация автора на выступление (`Registration.objects.create`); пользователь редактирует/удаляет **только свои** регистрации.
3. Отзывы к конференциям: рейтинг 1–10 + текст + дата конференции (берётся из связанной `Conference`) + автор — доступно авторизованным пользователям.
4. Админ через Django-admin выставляет `recommended_for_publication` у `Registration` — обычным пользователям это поле недоступно.
5. Публичная таблица "все участники по конференциям" (`Registration` + `Conference` + `user`, с пагинацией).

## Права в клиенте (не только через django-admin)
В шаблонах — проверка `{% if user.is_staff %}`: staff видит доп. действия (например, удаление чужих регистраций/отзывов), обычный пользователь — только свои.

## Для максимального балла
