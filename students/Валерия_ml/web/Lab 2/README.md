## Структура

Практики 2.1→2.2→2.3 — это **один** Django-проект, который наращивается по шагам: код лежит в `django_project_prosvetova/` (прямо в `Lab 2/`, на одном уровне со спеками, а не внутри `practice_2_1/`). Основное задание (вариант 5, конференции) — **отдельный** Django-проект в `main_task/`.

## Общие правила выполнения

- venv не создаёт агент — пользователь сделает сам позже.
- БД: практики 2.1–2.3 — дефолтный SQLite (как в задании, без Docker). Основное задание — PostgreSQL в отдельном Docker-контейнере (новый контейнер, тот же образ, что обычно используется).
- Когда дойдём до реализации: после выполнения шагов каждой спеки и **успешного запуска** (`runserver` + проверка нужной страницы/админки) — агент останавливается и ждёт пользователя (скриншот → продолжение). Не переходить к следующей спеке самостоятельно.
- Отчёт по всей ЛР2 (описание варианта + все реализованные интерфейсы) — на MkDocs, отдельным шагом после того как код готов.
